# 构图、字幕合成与实际 MP4 验收

工作室根目录：`$TTH_STUDIO_ROOT`。

## 构图与字幕
- 基线：`presets/avatar-composition-v1.json`，来自 2026-09-08 已导出的 9 秒样片及其 qa.json。
- 大画面 large.crop 与小窗 pip.crop 独立配置；不能把大画面裁切直接套给小窗。每个项目保存实际预设副本，镜头代码必须使用该副本，再检查额头、下巴、嘴部与手势安全区。当前基线为 contain；更紧的中近景需要实际渲染验证，不能标记为已验证。
- 基线为 1280×720，画布变化时重算人物和字幕区。4.59/5.24 秒为样片切换起止，不是通用时间点；按新音频停顿定位。
- HyperFrames 负责画面，最终使用 FFmpeg subtitles 滤镜烧录锁定 BaoCut SRT；FontName/FontSize/颜色/边距及编码参数见预设。
- 新项目优先不渲染 HTML 字幕，避免重复叠字。旧样片需用预设 clear_band 覆盖底部旧字幕后烧录；仅当该区域没有需保留内容时适用。
- 最终音频只映射锁定 voice.wav，一路音轨；不叠加 HeyGen 音轨。时长从本项目音频/视频读取，不沿用样片 9.3 秒常量。

## 实际导出验收
执行工作室 `scripts/review_export.py FINAL.mp4 --preset PROJECT-PRESET.json --switch 切换开始 --switch 切换结束 --pip-start 小窗稳定开始 --out 新验收目录`。每个镜头切换都传入；无切换的视频可传 --switch 0 作为开头检查点。

工具解码真实 MP4，保存开头、所有切换前中后、结尾帧，生成带原片声音的三倍小窗视频，以及绑定成片和预设 SHA-256 的 review.json。它只证明文件可解码，不会自动判定字幕正确或口型同步。

检查人须看实际 MP4：
1. 开头字幕是否出现、正确、清晰，首音是否完整。
2. 所有切换点前中后字幕有无丢失、残留、重叠，人像有无变形或被裁。
3. 结尾字幕、最后一个音节和自然收尾是否完整。
4. 播放 pip-mouth-review.mp4，听声音看嘴部，检查明显提前/滞后及切换后的同步；静帧不能证明嘴型同步。

把检查人、时间点、结论和问题记入 review.json；全部通过才写 pass，未检查保持 pending。重导出后 hash 变化，重新生成证据并检查受影响部分；预览正常不能复用为导出通过。
