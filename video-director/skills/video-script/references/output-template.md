# 视频导演稿输出模板

只保留本次任务适用的章节。方向未确认时只输出方向卡；确认后才输出导演契约与 Beat Graph。默认管线无关，只有用户明确指定工具时才加入 `pipeline` 和应用附录。

```markdown
---
title: 标题
date: YYYY-MM-DD
type: 视频导演稿
status: 方向待确认 / 导演稿已确认 / 待制作规格
platforms: [目标平台]
formats: [真人主导/证据演示/动效隐喻/混合]
duration: 预估时长
source: [逐字稿来源]
source_version: [逐字稿版本/日期]
audio_source: [已锁定完整音频路径]
audio_hash: [音频哈希]
audio_duration: [音频精确时长]
captions_source: [主字幕/对齐数据路径]
captions_hash: [字幕哈希]
direction_version: [方向版本]
approval_mode: standard / yolo
approval_provenance: [用户决定或委托授权的 message/task/session locator；YOLO 必填]
tags: [视频导演, 视频脚本]
# pipeline: 仅在用户明确指定 Remotion/ChatCut/HyperFrames/其他工具时加入
---

## Anti-PPT 检查

> 不复述前文。只勾选结果，并在末尾写仍未通过的例外和对应整改。

- [ ] 全片只有一个清楚的观看记忆
- [ ] 有贯穿物或稳定视觉关系
- [ ] 已锁定模板或背景时，已查看参考图并写清固定层与内容关系
- [ ] 视觉词典来自原稿，不是通用素材包
- [ ] 真实可展示内容没有被抽象卡片或隐喻替代
- [ ] 每个 beat 有具体主承载物、起止状态和事件/静止理由
- [ ] 动效主导 beat 有一个主运动原语、最多一个辅助运动和明确可读锁定
- [ ] 相邻 beat 有对象、方向、镜头、声音或问题接力
- [ ] 连续三个 beat 没有复用相同布局、进场和节奏
- [ ] 重要运动通过删除测试
- [ ] 没有重复 `opacity+y`、统一漂浮呼吸、无锚装饰线、通用粒子/AI 图标或空白淡出重启
- [ ] 重要转场中点可解释且可验收
- [ ] 下游不可静默重新导演

- 未通过项 / 整改：无 / 列出 beat ID 与动作

## 短视频留存检查（按需）

> 不复述留存契约；只记结论和必须回到上游的 cue。

- [ ] `0–2s` 不读完整字幕仍有第一眼目标、语义事件和可感知回报
- [ ] 首次有效兑现是真答案、结果、证据或可执行收获，不是继续预告
- [ ] 中段每次注意力重置都改变了理解、证据或情绪状态，不是定时加效果
- [ ] 钩子承诺在画面中被看见、证明或有理由地保持不可见，不是只用大字复读
- [ ] 结尾完成开头承诺的视觉收束，CTA 依附于真实落点
- [ ] 留存设计实际改变了镜头选择，不是只多了标签或表格

- 上游阻塞 / 整改：无 / 列出准确 cue 与原因
```
