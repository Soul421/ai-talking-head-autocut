# 封面模板参数表（可选策略工具箱）

> 这套参数源自“信息密度 × 视觉锚点”方法论，作为 `design-playbook.md` 的具象补充。
>
> **重要定位**：这里的模板是**可选工具箱，不是默认套路**。本 skill 的核心仍然是简约大方、标题一眼读懂、反模板自由创作。
> 用模板只是为了在选定一种视觉策略后，有现成的锚点位置、配色 HEX、字重比和对比度可参考；
> 不要因为有了模板就开始堆色块、堆小字、堆装饰。**简约优先级永远高于信息密度。**
>
> **工具约束**：所有参数最终都翻译进系统 `imagegen` / `image_gen` 的生图提示词，由模型一次生成完整发布图；涉及 IP/人物时必须同时带上参考图作为 identity reference。
> 禁止用代码 / Canvas / Pillow / ImageMagick 按这些参数去拼贴或叠字。

---

## 怎么用

1. 从标题类型在下面的矩阵里挑**一个**模板方向（不要混搭多个模板）。
2. 读对应模板的锚点位置、配色组、字重层级，作为写提示词时的参考值。
3. 按 `design-playbook.md` 的提示词结构，把这些参数自然融进提示词，但保持画面克制。
4. 知识 / 工具 / 教程类内容主要用前三套（冲突型 / 数字型 / 截图型）；情绪型在做观点共鸣、生活向选题时备用。

## 模板选择矩阵

| 标题 / 内容类型 | 推荐模板 | 核心锚点 | 泊舟 IP 是否登场 |
|---|---|---|---|
| 观点 / 纠错 / 方法论 | 冲突型 | 人脸 + 标题撞色区 | 适合，IP 当人脸锚点 |
| 干货 / 教程 / 步骤 / 清单 | 数字型 | 大号数字本身 | 可选，通常不抢镜 |
| 案例 / 结果 / 工具测评 / 前后对比 | 截图型 | 截图内容 + 标注 | 可选，多为辅助 |
| 情感共鸣 / 生活向 / Vlog | 情绪型 | 人脸（天然最强锚点） | 适合，IP 当主角 |

## 🔴 冲突型

**公式**：反直觉标题 × 强对比色 × 人物遮罩
**适用**：观点输出、AI 工具介绍、方法论、纠错提醒（泊舟 IP 天然契合）

### 结构参数

| 元素 | 规格 |
|------|------|
| 锚点位置 | 人脸居中偏下 + 标题在上 1/3 |
| 锚点逻辑 | 人脸引导注意力 → 视线上移到标题 |
| 主标题位 | 上 1/3，左对齐或居中 |
| 人物遮罩 | 占画面 50%-70%，底部出血 |
| 背景分区 | 上 2/3 强色背景 + 下 1/3 人物区 |

### 配色组（主色 / 撞色 / 底色）

| 配色组 | 主色 | 撞色 | 底色 | 情绪 |
|--------|------|------|------|------|
| 权威红 | #C0392B | #F7F7F7 | #1A1A1A | 紧迫、专业 |
| 科技蓝 | #2471A3 | #F1C40F | #0D1B2A | 理性、前沿 |
| 警示橙 | #E67E22 | #FFFFFF | #2C2C2C | 警示、干货 |
| 高级黑 | #1A1A1A | #E74C3C | #F5F5F0 | 极简、高端 |

### 字重层级

- 主标题：粗体（Bold），字号比副标题大 2-3 倍
- 副标题：中等（Medium），用主色的撞色
- 角标 / 标签：细体（Light），小字带色块底

## 🟡 数字型

**公式**：大号数字锚点 × 色块分割 × 悬念副标题
**适用**：干货攻略、步骤教程、清单、成果展示、工具测评

### 结构参数

| 元素 | 规格 |
|------|------|
| 锚点位置 | 中心大号数字（数字即锚点） |
| 数字字号 | 占画面高度的 30%-40% |
| 色块分割 | 横向或斜向分割，2 色或 3 色 |
| 悬念副标题 | 数字上方或下方，留出“为什么”的悬念 |
| 留白 | 数字周围保留呼吸感，不要塞满 |

### 配色组

| 配色组 | 主色 | 撞色 | 底色 | 适用内容 |
|--------|------|------|------|---------|
| 珊瑚活力 | #E74C3C | #FFFFFF | #FDF6EC | 生活干货 |
| 薄荷清新 | #1ABC9C | #2C3E50 | #F0FFFE | 健康 / 技巧 |
| 深蓝学术 | #154360 | #F1C40F | #FDFEFE | 知识 / 学习 |
| 暖橙收益 | #F39C12 | #1A1A1A | #FFFBF0 | 变现 / 收益 |

### 字重层级

- 数字：超粗体（Black / Heavy），占满版面
- 单位词（天 / 个 / 步 / 万）：中等，数字旁小字
- 副标题：细体，颜色弱化，制造层次

### 悬念副标题公式

```
数字 + [做什么] + [结果 / 转变] + ？
例：7 天 + 学会用 AI 做视频 + 真的可以吗？
例：3 个方法 + 让封面点击率翻倍
```

## 🟢 截图型

**公式**：真实截图遮罩 × 手写感标注 × 低饱和底色
**适用**：案例分享、工具测评、结果展示、前后对比、对话截图

### 结构参数

| 元素 | 规格 |
|------|------|
| 锚点位置 | 截图本身（真实感 = 可信度） |
| 截图位置 | 居中略偏下，上方留标题位 |
| 截图角度 | 轻微旋转 2-5 度，增加随意感 |
| 标注元素 | 手写圆圈、箭头、下划线，引导注意力 |
| 底色 | 低饱和，不抢截图风头 |

### 配色组（底色 / 标注色 / 标题色）

| 配色组 | 底色 | 标注色 | 标题色 | 适用内容 |
|--------|------|--------|--------|---------|
| 暖米纸感 | #F5F0E8 | #E74C3C | #1A1A1A | 生活攻略 |
| 冷白简约 | #F8F9FA | #2471A3 | #1A1A1A | 工具测评 |
| 马卡龙粉 | #FDE8F0 | #C0392B | #2C2C2C | 情感 / 生活 |
| 深色沉浸 | #1A1A2E | #F1C40F | #FFFFFF | AI / 科技 |

### 真实感要素（关键）

截图型成败在“真实感”，提示词里要避免：

- ❌ 截图太完美（要有轻微阴影、边缘感）
- ❌ 底色太鲜艳（会抢截图的视觉权重）
- ❌ 标注太工整（要像手写、手画）
- ✅ 截图轻微投影、轻微旋转
- ✅ 标注用红色或荧光色

> 注意：不要让模型编造虚假数据、伪造品牌 logo、伪造收益截图。只在用户提供真实信息时使用具体数字。

## 🔵 情绪型

**公式**：全出血人物图 × 单行大字 × 撞色条
**适用**：情感共鸣、生活向、Vlog、故事内容（泊舟 IP 可当主角）

### 结构参数

| 元素 | 规格 |
|------|------|
| 锚点位置 | 人脸（占画面 40%-60%） |
| 人物位置 | 居中或下 2/3，上方留文字区 |
| 文字区 | 上 1/3 叠半透明色条或直接压字 |
| 撞色条 | 水平色条，高度约画面 15%-20%，置于上或下 |
| 字数 | ≤ 8 字，越少越有力 |

### 配色组（撞色条 / 字色 / 配图色调）

| 配色组 | 撞色条 | 字色 | 配图色调 | 情绪 |
|--------|--------|------|---------|------|
| 激情红 | #C0392B | #FFFFFF | 暖色人物 | 励志 |
| 忧郁蓝 | #154360 | #FFFFFF | 冷色人物 | 思考 / 治愈 |
| 阳光橙 | #F39C12 | #1A1A1A | 暖阳人物 | 积极 / 温暖 |
| 高级灰 | #2C2C2C | #FFFFFF | 任意人物 | 优雅 / 高端 |
| 纯黑沉浸 | 无色条直接压字 | #FFFFFF | 任意 | 电影感 |

### 字重层级

- 主标题：超粗体，字号极大，占满撞色条宽度
- 字数：≤ 8 字（超过就换模板）

## 通用锚点与可读性规则

### 人眼扫描路径

- Z 轴：左上 → 右上 → 左下 → 右下
- F 轴：上方横向 → 左边纵向
- **结论**：最强位置是左上和上方水平中心，标题优先放这里。

### 80px 缩略图测试（硬标准）

封面缩到约 80px 宽（手机信息流缩略图尺寸），仍要满足：

- 主标题还能读
- 只有一个锚点最先被看到
- 色块仍然分明

不满足就改提示词重做，不要交付。

### 色彩对比度阈值

| 场景 | 最低对比度 |
|---------|----------|
| 主标题 vs 背景 | 4.5:1 |
| 副标题 vs 背景 | 3:1 |
| 缩略图模式 | 建议 ≥ 7:1 |

安全搭配：黑 / 黄、白 / 红、白 / 深蓝、黑 / 珊瑚、深绿 / 米白
高风险搭配：浅绿 / 白、米色 / 浅灰、红 / 橙、蓝 / 紫（无白色分隔）

### 标题字数建议

| 模板 | 主标题中文字数 |
|---|---|
| 冲突型 | 6-12 字 |
| 数字型 | 数字 + 4-10 字 |
| 截图型 | 8-14 字 |
| 情绪型 | 4-10 字 |

超过 16 字就拆：封面主标题保短、利益导向；其余信息降到副标题 / 标签。
