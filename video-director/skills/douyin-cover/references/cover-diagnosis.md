# 封面诊断与改版

当用户给出一张**已有封面**、问“这封面为什么没人点 / 帮我改一下 / 点击率怎么提升”时，用这套流程：先打分诊断，再给改版方向，最后按本 skill 正常流程用系统 `imagegen` / `image_gen` 重做。

> 工具约束不变：诊断只是分析，重做仍然必须用系统 Image Gen 一次生成完整发布图，禁止用代码改字、补字、拼背景或局部合成。涉及泊舟 IP 或其它指定人物/IP 时，必须先加载参考图并作为 identity reference 使用。

## 输出格式

按这个结构给诊断结论，话要直接，不要吹捧弱封面：

```markdown
## 诊断

模板匹配：<冲突型 / 数字型 / 截图型 / 情绪型 / 混乱>
主要问题：<一句话>
流失风险：<用户为什么会在信息流里划走>

## 打分

- 信息密度：<1-10>
- 视觉锚点：<1-10>
- 缩略图可读性：<1-10>
- 色彩对比：<1-10>
- 可信度 / 真实感：<1-10>

## 改版方案

1. <最高优先级的改动>
2. <第二项>
3. <第三项>

## 重做计划

<按 design-playbook + template-formulas 写出的新生图提示词要点，准备用系统 Image Gen 重做>
```

## 10 项审查

1. **模板匹配** — 内容类型和模板对不对？观点纠错配冲突型、步骤清单配数字型、案例测评配截图型、情感生活配情绪型。
2. **一眼承诺** — 3 秒内能不能看懂利益点？抽象口号、超长文章标题、看不懂的隐喻都是弱信号；副标题扛着真正利益、主标题却什么都没说，也算弱。
3. **视觉锚点** — 必须有一个最强停留点（人脸 / 大数字 / 截图 / 前后对比 / 结果面板 / 强剪影主体）。所有元素权重相等 = 没有锚点。
4. **锚点位置** — 标题放上 1/3；数字 / 对比 / 手机放中心；人脸 / 主体放下中部；分类小标签放左上。除非刻意引导，不要把最重要的锚点丢在右下角。
5. **缩略图测试** — 缩到约 80px 宽：主标题还能读、锚点仍明显、色块仍分明算过；标题糊成纹理、截图细节消失、浅色低对比字消失、超过两组文字在抢戏算挂。
6. **文字层级** — 三级：主标题占文字权重 60%-75%，辅助行 20%-30%，标签 5%-10%。标签比主标题还抢眼就缩小它。
7. **色彩对比** — 主标题 vs 背景 ≥ 4.5:1，缩略图争取 7:1。安全：黑/黄、白/红、白/深蓝、黑/珊瑚、深绿/米白；高风险：浅绿/白、米色/浅灰、红/橙、蓝/紫无白分隔。
8. **文字长度** — 冲突型 6-12 字、数字型 数字+4-10 字、截图型 8-14 字、情绪型 4-10 字。超过 16 字就拆主标题 / 副标题 / 正文标题。
9. **可信度信号** — 冲突型靠自信人脸+鲜明立场；数字型靠具体数目+简单承诺；截图型靠可信界面+标注；情绪型靠真实表情+自然场景。避免密集看不清的假界面、假 logo、编造的收益数字。
10. **平台适配** — 抖音 / 小红书被快速小图扫读：默认 3:4、重磅标题、少于 3 个文字区、没有解释性段落。公众号头图更宽，用更少的巨大主体、更平衡的横向构图。

## 常见问题与改法

| 问题 | 诊断 | 改法 |
|---|---|---|
| 好看但没人点 | 信息密度弱 | 围绕利益点重写标题 |
| 文字一堆没焦点 | 没有视觉锚点 | 选一个锚点放大 |
| 截图封面显得假 | 太精致 / 没标注 | 加手写标注 + 真实投影 |
| 治愈风看不清字 | 对比太低 | 加深文字或加半透明文字条 |
| AI 工具封面太通用 | 没证据 / 没分类 | 换截图型或科技数字型 |
| 情绪封面像图库图 | 主体表情弱 | 更紧的人脸特写或加直白标题 |
| 教程像文章配图 | 解释性排版 | 做成真正的封面，不是说明图 |

## 改版顺序

1. **先重写封面标题**（最高杠杆）。
2. 选一个模板（参考 `template-formulas.md`），不要混搭。
3. 选一个锚点。
4. 定两个主色 + 一个强调色。
5. 定标题位置。
6. 按 `design-playbook.md` 写完整生图提示词，用系统 `imagegen` / `image_gen` 重做。
7. 跑 80px 缩略图测试。

## 标题改写句式

```
不要再 <错误行为>
<数字> 个 <结果> 方法
改前 VS 改后
<工具 / 产品> 这样用
先别 <常见错误>
<情绪状态>，然后呢
```
