# 泊舟 IP 人物参考

原始头像参考图：`../assets/bozhou-avatar-reference.jpg`

规范化卡通参照图：`../assets/bozhou-ip-canonical-cartoon-reference.png`

生成封面时，人物一致性不能只靠文字描述。本封面 skill 的默认路径是系统 `imagegen` / `image_gen`，支持先用 `view_image` 把本地参考图放进上下文；因此只要封面出现泊舟 IP，就必须把至少一张参考图作为人物 identity reference：

- 优先使用原始头像参考图锁定身份、发型轮廓、脸型和眼镜。
- 需要更干净、更适合封面复用的卡通 IP 锚点时，同时使用规范化卡通参照图。
- 参考图的角色是“同一个人”，不是泛化的“黑发眼镜程序员”。

## 稳定识别特征

- 年轻男性程序员，日系动漫/轻漫画质感。
- 黑色蓬松短发，顶部有自然翘起的发束，刘海略遮额头，侧后方发量蓬松但不夸张，发丝有自然层次和少量高光。
- 黑色矩形粗框眼镜，镜框不能变成圆框、细框、透明框或无框。
- 脸型偏清瘦、下颌线干净，五官冷静温和，整体气质专注、聪明、有亲和力。
- 常见服装为浅蓝色衬衫，也可以按主题替换为相近的冷色上衣，但不要变成陌生人。

## 使用方式

IP 是系列锚点，不是模板。每张封面只要保留足够的识别特征即可，姿势、表情、镜头和画面位置都交给具体标题和系统 Image Gen 自由决定。不要在 IP 参考里预设固定场景、道具或动作。

在封面提示词里加入这段人物一致性约束：

```text
人物/IP：使用提供的泊舟头像参考图作为 identity reference。必须画成同一个人，而不是泛化的黑发眼镜程序员。保留黑色蓬松短发的整体轮廓、顶部微翘发束、略遮额头的刘海、黑色矩形粗框眼镜、清瘦温和脸型、浅蓝色衬衫和冷静专注的程序员气质。可以改变姿势、表情、镜头角度和手部动作，但不要改变脸型、发型轮廓、眼镜类型、发色、年龄感和服装主色。人物只做封面辅助锚点，不抢标题。
```

如果用户明确要求的非默认工具不支持参考图，仍然使用上面的文字约束，但要降低人物占比，避免让一个不稳定的人脸成为封面第一视觉。文字提示词只能约束大类特征，不能保证每次都长得像同一个人；默认系统 Image Gen 流程不得省略参考图。

避免：

- 每次都做成同一个右侧半身像。
- 把人物画成完全不同的发型、圆框眼镜、无眼镜、厚重赛博装甲、陌生职业、成熟商务男、少年学生、欧美脸或 3D 塑料角色。
- 让人物抢掉标题或变成唯一主角。封面第一优先级仍然是标题清楚、简约大方、有点击理由。
