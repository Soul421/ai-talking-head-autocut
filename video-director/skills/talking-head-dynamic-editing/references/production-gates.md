# 制作与验收门

## 制作前

- 有当前版本的完整音频、字幕和口播稿，hash 一致。
- 节奏听审已通过；未通过时停止 HeyGen 和复杂画面制作。
- 数字人构图已经记录大画面和小窗的独立裁切；没有把未验证的紧裁切标为可靠。
- 每个 beat 有具体承载物、关键词、关系和退出时机。

## 代表片段

覆盖本片实际使用的代表构图与切换；纯人物口播无需为了验收添加花字或图解。检查：

1. 第一眼是否知道人物在讲什么；
2. 花字是否只强调关键词；
3. 关系动效是否能在静帧中看懂；
4. 动效完成后是否留够阅读时间；
5. 普通字幕是否始终独立、清晰、不丢失。

## 实际 MP4

从导出的 MP4 本身抽帧，不从预览截图判断。固定检查：

- 开头：首音、首句字幕和第一眼构图；
- 每个切换：切换前、切换中、切换后是否有残影、字幕丢失、人物变形或花字遮脸；
- 中段：关系节点和证据素材是否按音频语义完成；
- 结尾：最后字幕、最后音节和自然停留；
- 小窗：放大后播放带声音的嘴部检查视频，确认无明显提前或滞后。

脚本只能证明文件可解码、帧存在和 hash 可追踪；字幕语义、花字审美和嘴型同步必须由人播放判断并记录到 `qa-report.md`。重导出后 hash 变化，重新验收。

## 构图与连续播放复核

- 静帧：主次、对齐、留白、面部安全；有无无用途的页眉、重复标题与装饰；全屏阶段有无导出意外留下的上下底栏。
- 连续播放：文字能否读完、转场是否帮助理解、人物是否频繁缩放、图解完成后是否停稳并及时退出、字幕是否稳定。
- 在分镜里核对每次切换的表达收益；理由只是“换个画面”“到时间了”时，保持原构图或重新规划。
- 技术检查通过、模型静帧观察、人工播放与审美认可分开记录；前两者不能替代后两者。未获人工评价保持pending，不据此声称用户已认可。
